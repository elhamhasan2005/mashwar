# مِشوار | Mashwar

منصة تعلّم تفاعلية باللغة العربية تساعد المبتدئين على استكشاف مجالات التقنية، اختيار مسار مناسب، متابعة المهارات، والوصول إلى مصادر للتعلّم والتطبيق والفرص المهنية.

## المزايا

- واجهة عربية باتجاه RTL وتصميم متجاوب للشاشات المختلفة.
- تسجيل دخول تجريبي وإنشاء حساب محلي.
- ستة مسارات: تطوير الواجهات، تطوير الواجهات الخلفية، UI/UX، تحليل البيانات، تطبيقات الجوال، وPython.
- بحث في المسارات وتحديد المهارات المنجزة ومتابعة التقدم.
- موارد ومشاريع وروابط فرص مرتبطة بالمسار المختار.
- صفحات محمية وتوجيه باستخدام React Router.

## التقنيات

- React 19 وReact DOM
- Vite 8
- React Router 7
- JavaScript وCSS
- Web Crypto API لتجزئة كلمات مرور الحسابات المحلية في هذا النموذج التجريبي

## التشغيل محلياً

يتطلب Node.js وnpm.

```bash
npm install
npm run dev
```

افتحي رابط التطوير الذي يعرضه Vite، وغالباً يكون `http://localhost:5173`.

### أوامر إضافية

```bash
npm run lint
npm run build
npm run preview
```

## تسجيل الدخول التجريبي

- البريد: `demo@mashwar.app`
- كلمة المرور: `mashwar123`

يمكن أيضاً إنشاء حساب من صفحة «انضمي إلينا». الحسابات والتقدم محفوظان في `localStorage` على المتصفح الحالي فقط؛ هذا المشروع واجهة تجريبية ولا يتصل بخادم مصادقة أو قاعدة بيانات. لا تستخدمي كلمة مرور حقيقية أو تعيدي استخدام كلمة مرور شخصية هنا.

## هيكل المشروع

```text
src/
  components/   مكونات مشتركة وحماية المسارات
  context/      سياق المصادقة والتقدم
  data/         بيانات المسارات والمهارات
  layout/       تخطيط التطبيق والتنقل
  pages/        تسجيل الدخول ولوحة المتابعة والصفحات
  App.jsx       تعريف المسارات
  styles.css    الأنماط والتصميم المتجاوب
```

## ملاحظات

- المصادر والروابط المهنية تفتح مواقع خارجية، وقد تتغير محتوياتها أو توفرها.
- إنشاء الحساب في النسخة الحالية محلي وغير مناسب للاستخدام الإنتاجي متعدد المستخدمين.
